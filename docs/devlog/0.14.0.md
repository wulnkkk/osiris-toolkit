# osiris-toolkit v0.14.0 Dev Log

> Architecture refactoring — data model foundation layer, Simulation split, dead code removal

## Refactoring: Data Model Extraction (#60)

All diagnostic data classes (`Field`, `GridAxis`, `ParticleData`, `PhasespaceData`,
`TrackData`, `HistoryData`, `TimingsData`, `FieldInfo`, `ParticleInfo`, `TrackInfo`)
moved from `sim/diagnostics.py` to a new foundation module `_models.py`.

This eliminates 3 reverse dependencies where `io/` and `compute/` (bottom layer)
imported from `sim/` (middle layer). The new dependency hierarchy:

```
基础层: exceptions  _generated  _models  ← 新增
底层:   deck  io  units  compute       ← 可安全 import _models
中层:   sim (diagnostics → re-export shim)
```

**No public API changes** — `from osiris_toolkit.sim.diagnostics import Field`
still works via a backward-compatible re-export shim.

## Refactoring: Simulation Split (#62)

`Simulation` class (~1,120 lines → 382 lines core) split into focused modules:

| File | Lines | Content |
|------|-------|---------|
| `sim/simulation.py` | 382 | Core: `__init__`, `_discover*`, `to_dict`/`from_dict`, properties |
| `sim/_parse.py` | 126 | `_parse_iter_file`, `_parse_quantity`, history/timings parsers |
| `sim/_accessors.py` | 560 | `_DataAccessors` mixin: all `get_*` and `list_*` methods |
| `sim/_info.py` | 112 | `_InfoAccessors` mixin: `info_field`/`info_raw`/`info_tracks` |

`Simulation` inherits from both mixins — public API completely unchanged.

## Removal: Deprecated APIs

| Removed | Replacement |
|---------|-------------|
| `Analyzer` base class (`analysis/__init__.py`) | `Protocol` |
| `VisEngine` class (`vis/__init__.py`) | `PostProcessor` from `postproc` |
| `vis.kspace.compute_k_space` wrapper | `compute.fft.compute_k_space` |
| `vis.scattering.analyze_scattering` wrapper | `analysis.scattering.ScatteringAnalyzer` |

Callers in `cli.py`, `workflow/pipeline.py`, `vis/batch.py`, and `vis/parallel.py`
updated to use the replacement APIs.
