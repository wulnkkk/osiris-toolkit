# osiris-toolkit v0.11.0 Dev Log

> Export & Interop — VTK structured grid export, NPZ/CSV archive export, and lazy iteration sampling

## New Feature: NPZ/CSV Archive Export (#45)

`Field` and `ParticleData` gain `to_npz()` and `to_csv()` methods for simple data interchange:

```python
field = sim.get_field("e1", iteration=50)
field.to_npz("e1.npz")   # saves data + axes/iteration/time metadata
field.to_csv("e1.csv")   # 1D: index,value; 2D+: x1,x2,...,value

raw = sim.get_raw("electrons", 50)
raw.to_npz("particles.npz")   # saves all particle arrays + metadata
raw.to_csv("particles.csv")   # one row per particle, columns = quants
```

NPZ archives can be loaded back with `np.load()`. CSV files use comma delimiter (configurable). No new dependencies — pure numpy + stdlib `csv`.

## New Feature: VTK Structured Grid Export (#16)

`Field.to_vtk()` exports grid data to VTK format for ParaView/VisIt 3D interactive analysis:

```python
field = sim.get_field("e1", iteration=50)
field.to_vtk("e1")          # → e1.vtr (1D) or e1.vts (2D/3D)

# With physical coordinates from GridAxis
field = sim.get_field("e1", 50)
field.to_vtk("e1", converter=uc, x_unit="um", y_unit="um")
```

Under the hood: `io/vtk_exporter.py` wraps `pyevtk.hl.gridToVTK`. Coordinate arrays are built from `GridAxis` metadata or index ranges. Output format auto-detected: `.vtr` for rectilinear grids (1D/2D), `.vts` for structured grids (3D).

**Optional dependency**: `pip install osiris-toolkit[vtk]`

## New Feature: Lazy Iteration Sampling (#47)

`Simulation.list_iterations()` gains a `step` parameter, plus a `LazySimulation` wrapper for transparent subsampling:

```python
# Direct step parameter
iters = sim.list_iterations("e1", step=5)  # → [0, 5, 10, 15, ...]

# LazySimulation wrapper — all iterations transparently subsampled
from osiris_toolkit import LazySimulation

lazy = LazySimulation(sim, step=5)
lazy.list_iterations("e1")  # auto step=5
lazy.get_field("e1", 50)    # direct lookup (passthrough)
lazy.get_raw("electrons", 150)  # passthrough
```

`LazySimulation` delegates all methods except `list_iterations` to the underlying `Simulation` via `__getattr__`.
