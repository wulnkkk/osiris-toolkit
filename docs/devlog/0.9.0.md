# osiris-toolkit v0.9.0 Dev Log

> Particle Diagnostics â€?RAW particle visualization & analysis, TRACKS trajectory visualization & analysis

## Core Feature: RAW Particle Visualization (#23)

The two largest diagnostic coverage gaps are now filled. `PostVisHub` gains `pp.vis.raw` and `pp.vis.tracks` namespaces, following the same pattern as `pp.vis.field` / `pp.vis.energy`.

### vis/raw.py â€?RAW Particle Plots

Four plot functions covering the full RAW diagnostic space:

```python
raw = sim.get_raw("electrons", iteration=50)

from osiris_toolkit.vis.raw import (
    plot_raw_scatter, plot_raw_momentum,
    plot_raw_phasespace, plot_raw_energy_spectrum,
)

# 2-D position/momentum scatter, colour by energy/charge
plot_raw_scatter(raw, "x1", "x2", color_by="ene", output="scatter.png")

# 4-panel: p1-p2 scatter + p1/p2/p3 histograms
plot_raw_momentum(raw, bins=80, output="momentum.png")

# x-p phase-space projection from raw particle data
plot_raw_phasespace(raw, "x1", "p1", color_by="ene", output="phasespace.png")

# Energy histogram (log-log by default)
plot_raw_energy_spectrum(raw, bins=100, output="energy_spectrum.png")
```

All functions accept `color_by`, `cmap`, `alpha`, `marker_size` for visual tuning.

### vis/tracks.py â€?TRACKS Trajectory Plots

Three plot functions for particle tracking data:

```python
td = sim.get_tracks("track_electrons")

from osiris_toolkit.vis.tracks import (
    plot_tracks_orbit, plot_tracks_energy, plot_tracks_field,
)

# Orbit projection (x1-x2, x1-x3, x2-x3)
plot_tracks_orbit(td, "x1-x2", output="orbit.png")

# Per-track energy vs time (or mean Â± std envelope)
plot_tracks_energy(td, per_track=True, output="energy.png")

# Field component along track vs time or position
plot_tracks_field(td, "E1", vs="time", output="field_along.png")
```

`highlight_tracks` parameter allows emphasizing specific trajectories.
