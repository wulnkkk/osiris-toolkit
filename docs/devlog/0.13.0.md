## Simulation Lightweight Serialization

`Simulation.to_dict()` / `Simulation.from_dict()` enable AI agents to pass
simulation references between sub-tasks without pickle:

```python
state = sim.to_dict()        # {"path": "/output/dir"}
sim2 = Simulation.from_dict(state)  # rebuilds catalog from disk
```

## PipelineContext Snapshots

`PipelineContext.save_snapshot()` / `PipelineContext.load_snapshot()` enable
interrupt-resume for long-running pipelines:

```python
ctx.save_snapshot("checkpoint.json")
# ... interrupt, restart ...
ctx = PipelineContext.load_snapshot("checkpoint.json")
```

## PostVisHub Cache Management

`PostVisHub.invalidate_cache()` and `set_converter()` let AI agents safely
reuse a Hub instance when switching configurations.
