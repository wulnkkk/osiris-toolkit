# osiris-toolkit v0.13.0 Dev Log

> AI workflow improvements — custom exceptions, serialization, snapshots, cache management

## New Feature: Custom Exception Hierarchy (#54)

All 110 built-in exception raises replaced with 11 precise exception classes
inheriting from `OsirisToolkitError`. AI agents can now target specific error
types for fine-grained recovery:

```python
try:
    field = sim.get_field("e1", iteration=50)
except DataNotFoundError:
    # Skip gracefully — data doesn't exist at this iteration
    pass
except FormatError:
    # File corruption — alert user
    raise
```

**Exception tree**:

```
OsirisToolkitError
├── DataNotFoundError        — requested data/quantity/diagnostic doesn't exist
├── FormatError              — invalid or unrecognised file format
│   └── UnsupportedVersionError  — ZDF/HDF5 version too new
├── ValidationError          — parameter/input validation failed
│   ├── ShapeError           — array dimensions/shape mismatch
│   └── MissingParameterError — required parameter/config section missing
├── PipelineError            — pipeline step prerequisite not met
├── ConfigurationError       — Simulation/OsirisConfig invalid
├── UnitConversionError      — unit conversion failed
└── MissingDependencyError   — optional dependency not installed
```

## Simulation Lightweight Serialization

`Simulation.to_dict()` / `Simulation.from_dict()` enable AI agents to pass
simulation references between sub-tasks without pickle:

```python
state = sim.to_dict()        # {"path": "/output/dir"}
sim2 = Simulation.from_dict(state)  # rebuilds catalog from disk
```

## PipelineContext Snapshots

`PipelineContext.save_snapshot()` / `PipelineContext.load_snapshot()` enable
interrupt-resume for long-running pipelines:

```python
ctx.save_snapshot("checkpoint.json")
# ... interrupt, restart ...
ctx = PipelineContext.load_snapshot("checkpoint.json")
```

## PostVisHub Cache Management

`PostVisHub.invalidate_cache()` and `set_converter()` let AI agents safely
reuse a Hub instance when switching configurations.
