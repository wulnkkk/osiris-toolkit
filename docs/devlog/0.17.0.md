# osiris-toolkit v0.17.0 Dev Log

> HISTORY diagnostic support, flat filename fixes, batch parallel recovery, toolchain uv decoupling

## Breaking Changes

None.

## Architectural Decisions

### 1. HISTORY diagnostic: analysis + visualization

Previously HISTORY data could be discovered and parsed but had no analysis or
visualization path. Added `HistoryAnalyzer` (following `TracksAnalyzer` pattern)
and `plot_history_timeseries()` (following `plot_energy_timeline` pattern),
wired through `PostAnalysisHub`/`PostVisHub` and batch processing.

### 2. Toolchain decoupled from uv

`Makefile` and `.pre-commit-config.yaml` had hard-coded `uv run` prefixes,
blocking developers who use `pip + venv`. Removed all `uv run` prefixes;
commands now run directly, relying on an activated venv regardless of tool.

### 3. Flat filename support for DENSITY/RAW/PHA

Changed `_parse_iter_file` regex from greedy `(.+)` to `([^-]+?)` to properly
split `{quant}-{species}-{iter}.zdf` filenames. Added flat-file fallback in
`_discover_species_dir`, `_discover_raw`, and `_discover_phasespace`.
