# osiris-toolkit v0.8.0 Dev Log

> Visualization Enhancement â€?field comparison plots, animation, coordinate transforms, float-index interpolation, and symmetric colormaps

## Core Feature: Field Float-Index Bilinear Interpolation (#38)

`Field.__getitem__` now supports float indices for bilinear interpolation alongside existing integer slices:

```python
field = sim.get_field("e1", iteration=44100)

# Integer slicing (existing)
roi = field[0:10, 0:5]

# Float index â†?bilinear interpolation (NEW)
val = field[2000.5, 1800.3]        # â†?float
line = field[:, 1800.5]              # â†?1D Field along x1
```

Float indices are clamped to `[0, npoints-1]` range, producing safe results even for out-of-bounds values.

### vis/comparison.py â€?Field Difference and Overlay (#35)

```python
from osiris_toolkit.vis.comparison import plot_difference, plot_overlay

# Spatial difference between two iterations
plot_difference("e1", iter_a=0, iter_b=44100, sim=sim, cmap="RdBu_r")

# E/B field overlay
plot_overlay(["e1", "b3"], iteration=44100, sim=sim, alpha=0.5)
```

The overlay renders the first quantity as a full `imshow` layer and the second as a semi-transparent overlay, each with its own colorbar.

### vis/animation.py â€?Time-Evolution Animation (#36)

```python
from osiris_toolkit.vis.animation import animate_field

# Generate GIF from all field iterations
animate_field("e1", sim=sim, output="e1_evolution.gif", fps=10)

# Subset of iterations
animate_field("e1", sim=sim, output="e1_subset.gif",
              iterations=[0, 900, 1800, 2700, 3600, 44100])
```

Each frame is rendered via `plot_field()` with consistent color scaling across frames. Requires `imageio` (`pip install imageio`).
