# osiris-toolkit v0.10.0 Dev Log

> Toolchain Enhancement — global OsirisConfig, particle filter syntax, BatchResult + progress_callback, and Pipeline dry_run mode

## Core Feature: Global OsirisConfig (#52)

Unified layered configuration replaces scattered parameters across modules.

```python
from osiris_toolkit.config import OsirisConfig

# Global setup (once, at application startup)
OsirisConfig.get().set(
    output_root="/data/figures",
    parallel_workers=4,
    x_unit="um", y_unit="um", time_unit="ps",
)

# Read current config
cfg = OsirisConfig.get()
print(cfg.output_root)  # Path("/data/figures")

# Per-simulation override
sim_cfg = OsirisConfig.get().copy_with(output_root="/other/path")
sim = Simulation("/path/to/output", config=sim_cfg)
```

**Configuration cascade**: explicit kwarg > `sim.config` > global `OsirisConfig` > hardcoded default.

**Fields**: `output_root`, `log_level`, `log_json`, `parallel_workers`, `overwrite`, `x_unit`, `y_unit`, `time_unit`.

### Integration Points

- `Simulation.__init__` accepts `config` parameter
- `save_or_show()` reads `config.overwrite` when not explicitly passed
- CLI `--verbose`/`--quiet` sets `config.log_level`
- `process_simulation()` defaults read from config (future)

## New Feature: Particle Filter Syntax (#43)

`ParticleData` gains `filter()` and `compress()` methods with class-pandas string expressions:

```python
raw = sim.get_raw("electrons", iteration=50)

# String expression filtering
hot = raw.filter("p1 > 0 and ene < 10")
print(len(hot))  # number of particles after filter

# Chaining
subset = raw.filter("p1 > 0").filter("ene < 10")

# Empty result
empty = raw.filter("p1 > 9999")
assert len(empty) == 0

# compress() — returns contiguous copy independent of source
independent = raw.filter("p1 > 0").compress()
```

Internal implementation tries `numexpr` (optional dependency) first, falls back to `eval()` with restricted namespace (`{"__builtins__": {}}`). If `numexpr` is installed, multi-condition expressions like `"p1 > 0 and ene < 10"` are fully supported.

Install with numexpr:
```bash
pip install osiris-toolkit[numexpr]
```

## New Feature: BatchResult + progress_callback (#44)

`process_simulation()` now returns structured results and accepts a progress callback:

```python
from osiris_toolkit.vis.batch import process_simulation, BatchResult, ProgressEvent

def on_progress(event: ProgressEvent):
    print(f"Iteration {event.iteration}/{event.total} "
          f"({event.elapsed:.1f}s, ETA {event.eta:.0f}s)")

result: BatchResult = process_simulation(
    "/data/sim", "run01",
    progress_callback=on_progress,
)

print(f"Generated {len(result.files)} files")
print(f"Elapsed: {result.elapsed:.0f}s")
print(f"Errors: {len(result.errors)}")
for err in result.errors:
    print(f"  - {err}")
```

`BatchResult` fields: `sim_name`, `files` (list of Path), `elapsed`, `errors` (list of str).  
`ProgressEvent` fields: `iteration`, `total`, `elapsed`, `eta`.

## New Feature: Pipeline dry_run Mode (#55)

`PipelineContext(dry_run=True)` previews pipeline execution without running steps:

```python
from osiris_toolkit.workflow.pipeline import Pipeline, PipelineContext

ctx = PipelineContext(dry_run=True)
pipe = Pipeline([DeckParseStep("input.in"), SimLoadStep("output/")])
pipe.run(ctx)

# Output:
# [INFO] [DRY RUN] Would execute: deck_parse
# [INFO] [DRY RUN] Would execute: sim_load
```

Each step's name is logged at INFO level when in dry_run mode. Default behavior (`dry_run=False`) is unchanged.
