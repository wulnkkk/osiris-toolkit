# osiris-toolkit v0.5.0 Dev Log

> Path Input/Output Architecture — Simulation owns path resolution, outputs default in-place

## Core Feature: Output Anchor Architecture

`Simulation` is now the single authority for path resolution and output derivation. All downstream code receives absolute paths. Output defaults to `{sim_path}/figures/` in-place.

### Simulation Path Ownership

`Simulation.__init__` resolves `path` to absolute immediately. New `output_root` parameter (default: `{path}/figures/`) controls where analysis/visualisation outputs are written.

| Property / Method | Description |
|-------------------|-------------|
| `Simulation.path` | Absolute path to the simulation output directory |
| `Simulation.output_root` | Absolute path to the output root directory |
| `Simulation.output_dir(*parts)` | Create and return a subdirectory under `output_root` |

```python
s = Simulation("/data/sim", output_root="/results")
print(s.path)         # → /data/sim
print(s.output_root)  # → /results
d = s.output_dir("fields")  # → /results/fields/  (created)
```

### Auto-Output from Plot Functions

All plot functions now auto-derive an output file path when `output=None` and a `sim` is provided. No more manually constructing output paths.

```python
# Before
plot_field("e1", 50, sim_path="/data/sim", output="/data/sim/fields/e1_000050.png")

# After — auto-saves to {sim.output_root}/fields/e1_000050.png
plot_field("e1", 50, sim=sim)
```

All six plot functions return `Path | None` (the saved file path, or `None` if shown interactively):

| Function | Auto-output subdirectory | Filename pattern |
|----------|--------------------------|------------------|
| `plot_field()` | `fields/` | `{quantity}_{iteration:06d}.png` |
| `plot_density()` | `density/` | `{species}_{iteration:06d}.png` |
| `plot_k_space()` | `k_space/` | `{quantity}_{iteration:06d}.png` |
| `plot_phasespace()` | `phasespace/` | `{ps_name}_{species}_{iteration:06d}.png` |
| `plot_composite()` | `composite/` | `composite_{iteration:06d}.png` |
| `plot_scattering_fraction()` | `scattering/` | `scattering_{quantity}.png` |

### `save_or_show()` Auto-Creates Parent Directories

`save_or_show()` now calls `mkdir(parents=True, exist_ok=True)` before `savefig`, so output directories are always created on demand.

### Batch Processing: `output_root` Becomes Optional

`process_simulation()`, `batch_process_parallel()`, and `VisEngine.batch()` all accept `output_root=None` (the new default), which defaults to `Simulation.output_root`.

### CLI Changes

```bash
# Before: -o was required
osiris-toolkit vis batch -o /path/to/output /data/Au Au

# After: -o optional, defaults to {sim_path}/figures/
osiris-toolkit vis batch /data/Au Au
osiris-toolkit vis batch -o /path/to/output /data/Au Au  # explicit still works
```

`vis plot` prints the auto-generated output path when saved.

## Breaking Changes

None at the API level — all new parameters are optional with sensible defaults. Old code using explicit `output` paths continues to work unchanged.

Type annotations changed (`-> None` → `-> Path | None` on plot functions), but these are compatible at runtime.

## Backward Compatibility

| Old Pattern | Status |
|-------------|--------|
| `Simulation(path)` without `output_root` | Works, defaults to `{path}/figures/` |
| `plot_field("e1", 50, sim_path=..., output="out.png")` | Works, explicit output takes priority |
| `process_simulation(sim_path, name, output_root)` | Works, explicit `output_root` still accepted |
| `VisEngine.batch(name, output_root)` | Works, optional now |
| `vis batch -o /path ...` | Works, flag still accepted |
