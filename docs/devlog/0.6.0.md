# osiris-toolkit v0.6.0 Dev Log

> Post-Processing Architecture Refactor — compute/ → analysis/ → vis/ three-layer architecture with unified PostProcessor entry point

## Core Feature: Three-Layer Post-Processing Architecture

Established a clean separation of concerns across three layers:

| Layer | Directory | Responsibility |
|-------|-----------|----------------|
| compute/ | `src/osiris_toolkit/compute/` | Pure numerical transforms (FFT, integration). Numpy in, numpy out. |
| analysis/ | `src/osiris_toolkit/analysis/` | Physics-domain analysis. Each diagnostic type has an Analyzer class returning typed dataclasses. |
| vis/ | `src/osiris_toolkit/vis/` | Plotting/rendering. Consumes analysis result dataclasses or raw sim data. |

### compute/ — Pure Numerical Layer

New module providing stateless numerical functions:

- `compute_k_space(data, dx, dy, omega0_norm)` — 2-D FFT k-space spectrum
- `spectral_power(data, dx, dy, omega0_norm)` — |FFT|² power spectrum
- `mask_energy(spectrum, kx, ky, kx_range, ky_range)` — k-space region energy integral
- `trapz_2d(data, dx, dy)` — 2-D trapezoidal integration
- `line_integrate(data, axis)` — line-integrated profile along one axis

### analysis/ — Protocol-Driven Analysis

**DiagnosticAnalyzer ABC** (`_protocol.py`) — all analyzers implement `diagnostic_kind` and `list_available()`.

**Result dataclasses** (`_result_types.py`) — strongly-typed return values:

| Dataclass | Method |
|-----------|--------|
| `FieldEnergyResult` | `EMFAnalyzer.field_energy()` |
| `EMDynamicsResult` | `EMFAnalyzer.em_dynamics()` |
| `EMSpectrumResult` | `EMFAnalyzer.spectrum()`, `KSpaceAnalyzer.spectrum()` |
| `PoyntingResult` | `EMFAnalyzer.poynting()` |
| `ScatteringResult` | `ScatteringAnalyzer.analyze()` |
| `DensityProfileResult` | `DensityAnalyzer.profile()` |
| `DensityIntegralResult` | `DensityAnalyzer.total()` |
| `ParticleSpectrumResult` | `SpeciesAnalyzer.energy_spectrum()` |
| `TemperatureResult` | `SpeciesAnalyzer.temperature()` |

**New analyzers:** `DensityAnalyzer`, `ScatteringAnalyzer`, `KSpaceAnalyzer`, `PhasespaceAnalyzer` (placeholder).

### vis/ — Cleaned Up & Extended

**Moved out:** `compute_k_space()` → compute/, `analyze_scattering()` → analysis/.

**New:** `vis/energy.py` — `plot_energy_timeline()`, `plot_spectrum()`, `plot_poynting()`.

### PostProcessor — Unified Entry Point

```python
from osiris_toolkit.postproc import PostProcessor

pp = PostProcessor(sim)

# Analysis
result = pp.analyze.emf.field_energy("e1", iteration=50)  # → FieldEnergyResult
spec   = pp.analyze.kspace.spectrum("e1", iteration=50)   # → EMSpectrumResult

# Visualization
pp.vis.field.plot("e1", iteration=50, x_unit="um")
pp.vis.energy.timeline([result1, result2, ...])

# Batch
pp.batch(sim_name="run_01")
```
