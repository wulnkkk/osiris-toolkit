## Phase 1: Features

### ZDF-only documentation

Added a "Format Support" section to `README.md` and `docs/modules/io.md`, clearly stating the toolkit supports ZDF only, with guidance to set `file_format = "zdf"` in OSIRIS input decks.

### TIMINGS text parser

Added `TimingsData` dataclass and `Simulation.get_timings()` / `list_timings()` methods, completing support for OSIRIS's 13th diagnostic type. The parser handles both serial (single-column "Total [s]") and parallel (three-column "Avg/Min/Max [s]") output formats, reusing the `_parse_history_file()` pattern.

### `sim info` format detection

`Simulation.detected_format` property scans the `MS/` directory for file extensions and returns `"zdf"`, `"hdf5"`, `"mixed"`, or `"unknown"`. The CLI `osiris-toolkit sim info` command prints a yellow warning with migration guidance when HDF5 files are detected.

### Section name mapping

`sections.py` now includes `SECTION_ALIASES` (Fortran name â†?doc filename, 29 entries) and `DOC_TO_SECTION` (reverse mapping), auto-emitted to `_generated/sections.py`.
