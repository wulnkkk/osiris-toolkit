## Phase 1：功能增强

### ZDF-only 文档声明

在 `README.md` 和 `docs/modules/io.md` 明确声明 toolkit 仅支持 ZDF 格式，HDF5 输出目录会给出切换指引。

### TIMINGS 文本解析器

新增 `TimingsData` dataclass 和 `Simulation.get_timings()` / `list_timings()` 方法，补全 OSIRIS 第 13 种诊断类型。解析器支持串行（单列 Total [s]）和并行（三列 Avg/Min/Max [s]）两种输出格式，复用 `_parse_history_file()` 的解析模式。

### `sim info` 格式检测

`Simulation.detected_format` 属性自动扫描 `MS/` 目录下的文件后缀，检测输出格式（zdf/hdf5/mixed/unknown）。CLI 的 `osiris-toolkit sim info` 在遇到 HDF5 时给出黄色警告和切换指引。

## Phase 3：代码质量

### Reader 维度处理重构

在 `io/_reader.py` 提取 `_read_data_header()` 共享函数，消除 `_read_dataset` 和 `_read_cdset` 中的重复代码。纯内部重构，所有 IO 测试通过。

### 类型映射补全

审计确认 520 参数全部有正确 Python 类型（float: 276, int: 126, str: 68, bool: 50），无空白。`_type_to_python()` 的 fallback 逻辑覆盖了所有 Fortran 类型变体。

---

## Phase 4：完善

### Section 名称映射

`sections.py` 新增 `SECTION_ALIASES`（Fortran→文档名，29 个映射）和 `DOC_TO_SECTION`（反向映射），自动 emit 到 `_generated/sections.py`。

### 参数描述自动补全

新建 `sync/descriptions.py`，从 `osiris-1.0.0/docs/reference/*.md` 提取参数描述。26 个 section 的 297 个参数全部获得描述。`namelist.generate()` 新增 `docs_path` 参数，CLI 新增 `--docs-path` 选项。

### diag_species 参数审核

确认 `nl_diag_species` 仅在 `os-spec-diagnostics.f03` 一处定义，54 个参数与源文件一致。14 个 `fortran_type` 为空的是模块级声明的字符类型（`reports`、`phasespaces` 等），非多文件覆盖问题。
