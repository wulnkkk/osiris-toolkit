# Security Policy

## Supported Versions

The latest stable release of **osiris-toolkit** receives security updates.
Older versions are not actively patched — please upgrade to the latest version.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

We take security issues seriously. If you discover a security vulnerability in
osiris-toolkit, please **do not** open a public issue. Instead, report it
privately via **GitHub Security Advisory**:

1. Go to [https://github.com/wulnkkk/osiris-toolkit/security/advisories](https://github.com/wulnkkk/osiris-toolkit/security/advisories)
2. Click **"New draft security advisory"**
3. Fill in the details and submit

Alternatively, you can also report via email to the maintainer (if a contact
address is listed on the GitHub profile).

You should receive an acknowledgment within **72 hours**. We will keep you
informed of the progress toward a fix and release.

## Disclosure Policy

- The report will be reviewed and investigated promptly.
- A fix will be prepared and released as part of the next patch/minor version.
- Once the fix is released, we will publish a security advisory on GitHub.

Thank you for helping keep osiris-toolkit and its users safe.
